# Licensing

PatchNest is a mixed-license monorepo. Existing component licenses and upstream attribution remain authoritative.

- `cli/`: GPL-2.0; see `cli/LICENSE` and retained upstream notices.
- `module/`: GPL-3.0; see `module/LICENSE`.
- `module/webui/`: MIT; see `module/webui/LICENSE`.
- `kpms/`: source files retain their declared licenses and upstream copyright notices; release eligibility requires a confirmed compatible license.

`Zhanfg/KernelPatch-Public` is not part of this monorepo and keeps its own license and release history.

Do not remove component license files when moving or refactoring code.
